# Branches and `if`

This crate demonstrates conditional branching with `if`, `else if`, and `else`.

## Topics covered

- Conditions are boolean expressions; Rust does not require parentheses around them.
- Branches are checked in order, so the first matching branch runs.
- `if` is also an expression. When its result is assigned to a variable, every branch must produce the same type.

## Run

From this directory:

```sh
cargo run
```

Change the `number` value to try different branches. The final `if` expression shows how a conditional can produce a value.
